These concepts were generated before implementation and are the accepted visual reference for the first vertical slice:

## Extracted system

- Canvas: true white
- Foreground: deep near-black navy
- Accent: restrained grass lime
- Display typography: condensed, heavy, editorial
- UI typography: clean neutral sans-serif
- Geometry: thin rules, square to small radius
- Container model: open bands, lists, tables, and one purposeful product frame
- Motion: restrained hover and selection feedback
- Prohibited: sportsbook odds, money, profit claims, guaranteed wins, casino neon, decorative gradients, and generic bento grids
